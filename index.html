Protocolos computacionais

Guias internos de preparação e execução de fluxos computacionais usados pelo grupo.

Preparação para docking molecular (AutoDock Vina)

  1. Obtenção e limpeza da estrutura (PDB)

    Baixar as coordenadas da proteína em formato legacy PDB a partir do Protein Data Bank.

    • Abrir o arquivo em um editor de texto (ex: Notepad++) e verificar resíduos/átomos ausentes.
    • Se houver partes não resolvidas, modelar com SWISS-MODEL https://swissmodel.expasy.org/) ou ColabFold (https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/AlphaFold2.ipynb).
    • Remover ligantes, águas e demais moléculas do protocolo de cristalografia que não são de interesse (notepad++, Discovery Studio ou Pymol).
    • Usar a estrutura processada como entrada no ProteinPrepare -https://open.playmolecule.org/- (ou PDB2PQR -https://server.poissonboltzmann.org/pdb2pqr-) para avaliar estados de protonação (LYS, ARG, HIS, ASP, GLU, CYS) e adicionar hidrogênios faltantes.

  2. Preparação no MGLTools (https://ccsb.scripps.edu/mgltools/downloads/)

    Ligante

    • Read Molecule → Ligand → Input → Choose (selecionar a molécula para o AutoDock)
    • Ligand → Torsion Tree → Detect Root
    • Ligand → Torsion Tree → Choose Torsion → Done
    • Ligand → Output → Save as PDBQT

    Receptor

    • Deletar o ligante e abrir o receptor
    • Edit → Hydrogens → Add → Polar Only
    • Grid → Macromolecule → Choose (selecionar e salvar)
    • Grid → Grid Box → Spacing = 1

  3. Execução no AutoDock Vina (https://vina.scripps.edu/)

    Tamanho de célula de grade sempre em 1 Å.

    vina.exe --config conf.txt --log log.out

vina_split.exe --input nome_arquivo_saida.pdbqt

  4. Análise estrutural no PyMOL (https://www.pymol.org/)

    • Abrir o PDB do receptor no PyMOL
    • Abrir os ligantes gerados pelo vina_split

  5. Rescoring consenso(doi:10.1039/d1ra05785e, doi:10.1016/j.jmgm.2021.108023)

    Recomenda-se um rescoring consenso, comparando poses entre diferentes funções de scoring, para dar maior robustez à análise final.
